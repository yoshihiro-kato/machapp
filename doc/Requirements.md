# 出荷集計アプリ

## 計算の流れ
1. 使用者が、規格ごとの数値を入力する　数量のほか、出荷日、品種名も入力
2. B規格の小計、○規格の小計、全体の合計を算出する
3. C規格については、10㎏箱のため、パレット積みする上では2倍の数量とし、改めて合計を算出する
4. 3で算出した合計を参考に、使用者が、パレットの枚数を選択する（1から5の範囲）
5. 全体の合計を4で選択したパレットの枚数で割り、平均値を算出する
   パレットは、1段12箱、最大で12段（144箱）を上限とする
6. "全ての規格をパレットに分けて積む時に、各パレットに積む総数が5で算出した平均値に近い数量になる組み合わせを算出する
   規格ごとに同じパレットに積むものとし、複数のパレットには分けない"
   1. "すべての規格の内、数が多いものを最初に各パレットに分けて積むため、
      数量が多い上位の規格（パレットと同じ数）を選び、各パレットに分ける"
   2. "上位の規格の次に、そのほかの規格を積み、平均値に近い数量になるように配分する
      このとき、B規格と○規格、C規格は、同じパレットに優先的に配分する"

## パレットへの積み方
- 5㎏箱2つ重ねにしたものを1ピースとしてはい積みする。
- 1つの規格が奇数の場合は、1ピースの中で合積みとなる。
- C規格は10㎏箱のため、1箱で5㎏箱2つ分と同じ大きさになる。
