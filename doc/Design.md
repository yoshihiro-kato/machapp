# 出荷集計アプリ 設計書

## 1. 目的

本アプリは、出荷情報を入力し、規格別の数量と合計、パレット数、各パレットに積む目安数量、最適な積み分けを自動計算することを目的とする。

現在の実装は「2つの数値を足し算する簡易アプリ」であり、要件の出荷集計ロジックを満たす設計に置き換える必要がある。

---

## 2. 画面・用途

### 2.1 画面構成

1. 入力画面
   - 出荷日
   - 品種名
   - 規格ごとの数量
   - 規格一覧（FG / B規格 / ○規格 / C規格 / 正品など）

2. 集計結果画面
   - B規格小計
   - ○規格小計
   - 全体合計
   - C規格換算合計（10kg箱は 2 倍で計算）

3. パレット設定画面
   - パレット枚数（1〜5）
   - 平均積載数の算出
   - パレット上限（1段12箱、最大12段=144箱）

4. 最適積み分け結果画面
   - 各規格をどのパレットに載せるか
   - 1パレットあたりの総数と平均値との差分
   - 1規格が複数パレットに跨がない前提の配置結果


---

## 3. 要件整理

### 3.1 入力要件

- 使用者は、規格ごとの数量を入力する
- 追加で以下を入力する
  - 出荷日
  - 品種名
- 規格の区分は以下の分類を含む
  - FG
  - 正品
  - B規格
  - ○規格
  - C規格

### 3.2 集計要件

- B規格小計を算出する
- ○規格小計を算出する
- 全体合計を算出する
- C規格は 10kg 箱のため、パレット積みでは 2 倍数量として扱う
- 3 で得られた合計をもとに、使用者がパレット枚数を選択する
- 全体合計を選択枚数で割り、平均値を算出する
- パレット容量は 1段12箱、最大12段 144箱

### 3.3 配置要件

- 「全ての規格をパレットに分けて積む時に、各パレットに積む総数が平均値に近い数量になる組み合わせを算出する」
- 規格ごとに同じパレットに積むものとし、複数パレットに分けない
- 数量が多い上位の規格を優先して各パレットに分ける
- B規格と○規格、C規格は同じパレットに優先的に配分する

- 1段は 12箱まで
- 1パレットの最大積載は 12段 = 144箱

## 5. データモデル

### 5.1 入力データ

```js
{
  shipmentDate: '2026-09-12',
  varietyName: '品種A',
  items: [
    { standard: 'B3L', category: 'B', quantity: 120 },
    { standard: '○8', category: 'O', quantity: 90 },
    { standard: 'C', category: 'C', quantity: 30 }
  ]
}
```

### 5.2 計算用データ

```js
{
  bSubtotal: 0,
  oSubtotal: 0,
  total: 0,
  cAdjustedTotal: 0,
  palletCount: 0,
  averagePerPallet: 0,
  palletPlan: [
    {
      palletIndex: 1,
      totalQuantity: 0,
      standards: [
        { standard: 'B3L', quantity: 120 }
      ]
    }
  ]
}
```

### 5.3 重要な定義

- `quantity`: 各規格の出荷数量
- `category`: 区分（FG / 正品 / B / ○ / C）
- `cAdjustedTotal`: C規格を 2 倍換算した合計
- `averagePerPallet`: 全体合計 / パレット枚数
- `palletPlan`: パレットごとの配置結果

---

## 6. 処理フロー

### 6.1 主要処理

1. 入力フォームから出荷日・品種名・規格ごとの数量を取得する
2. 規格ごとに数量を正規化する
3. B規格小計・○規格小計・全体合計を計算する
4. C規格の数量を 2 倍換算して、再集計する
5. ユーザーがパレット枚数を選択する
6. 全体合計をパレット枚数で割り、平均積載数を計算する
7. 各規格を、同一パレットにまとめる前提で、平均値に近い組み合わせを探索する
8. 小計・平均・パレット計画を画面に表示する

### 6.2 数式

- B規格小計
  - `sum(各 B規格の qty)`

- ○規格小計
  - `sum(各 ○規格の qty)`

- 全体合計
  - `sum(全規格の qty)`

- C規格換算合計
  - `sum(C規格 qty) * 2`

- 平均積載数
  - `averagePerPallet = total / palletCount`

- パレット容量上限
  - `palletCapacity = 12 * 12 = 144`

---

## 7. パレット配置アルゴリズム

### 7.1 基本方針

- すべての規格をパレットごとに集約する
- 個々の規格は 1 パレットに集中させる
- 1 パレットの総数が平均値に近づくように配置する
- 大きい数量の規格から優先的に割り振る
- B規格と○規格、C規格は同じパレットに優先してまとめる

### 7.2 配置戦略

1. すべての規格を数量の大きい順にソートする
2. 先頭からパレットごとに分配していく
3. パレットの目標数は `averagePerPallet` を基準にし、各パレットの差分が最小になる組み合わせを選ぶ
4. 1 パレットあたりの合計が上限 144 を超えないように制限する
5. 既に割り振った規格は、別パレットに分けない
6. 最後に、各パレットの合計と平均値との差分を表示する

### 7.3 近似ロジック

現実装では、厳密な最適化よりも「探索的な近似計算」を採用するのが適切である。

- まず、対象規格を大きな順に並べる
- 各規格を既存パレットへ追加したときの適合度を計算する
- 追加後に平均値に近づくかどうかを判定する
- 近づく場合に優先して配置する
- どのパレットにも適合しない場合、新しいパレットを作成する

これにより、簡単なブラウザアプリでも、実用上十分な結果を出せる。

## 8. UI設計

### 8.1 入力フォーム

- 1 行ごとに以下を入力
  - 規格名
  - 数量
- 例: 「B3L / 120」
- 出荷日と品種名は必須入力
- 数量は正の整数入力のみ許可

### 8.2 集計表示

- B規格小計
- ○規格小計
- 全体合計
- C規格 2 倍換算
- パレット枚数
- 平均積載数

### 8.3 配置結果表示

- 各パレットの「総数」「規格一覧」「差分」を表示
- 例:
  - パレット 1: 120個, B3L 120
  - パレット 2: 90個, ○8 90
  - パレット 3: 95個, 3L 60 + C 35

---

## 9. バリデーション

- 出荷日が未入力の場合はエラー
- 品種名が未入力の場合はエラー
- 数量が未入力または 0 以下の場合はエラー
- 数字以外は弾く
- パレット数は 1〜5 の範囲内であること
- 1パレットあたりの総数が 144 を超えないこと
- 規格名が一覧に存在しない場合はエラー

---

## 10. 非機能要件

### 10.1 使いやすさ

- 入力フォームは見た目がシンプルでわかりやすい
- 数字の入力や結果の確認がしやすい
- すぐに計算結果が確認できる

### 10.2 保守性

- 計算ロジックと描画処理を分離する
- 関数を小さく分割する
  - `calculateSubtotals()`
  - `calculateCAdjustedTotal()`
  - `calculateAveragePerPallet()`
  - `buildPalletPlan()`
  - `renderSummary()`

### 10.3 拡張性

- 規格の追加・削除に対応しやすいように定数化する
- 品種ごとのデータ蓄積ができるように、将来的に CSV や localStorage に保存できる設計にする

## 13. まとめ

本アプリは、単純な足し算アプリではなく、出荷規格・数量・パレット積みを扱う業務計算アプリとして設計する。設計上の中心は、以下の 3 点である。

1. 規格ごとの正確な小計・全体合計
2. C規格の 2 倍換算と平均積載数計算
3. 平均値に近いパレット配分を算出するロジック

この設計により、サンプル実装を要件に沿う実務向けアプリへ成熟させることができる。
